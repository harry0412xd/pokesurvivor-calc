# PokéSurvivor Toolkit

**Version 1.6.7** — single-file self-contained calculator.

## Deploy

GitHub Pages: Settings → Pages → branch **main** / **(root)**

Site: https://harry0412xd.github.io/pokesurvivor-toolkit/

## Multipliers

| Name | Formula |
|------|---------|
| dmg multi | ATK × type multi × weather multi |
| dodge factor | median r² / r² (higher better) |
| ehp | dodge / (type def × weather def) (higher better; no species HP) |
| def multi | type def × weather def |

Live game data is fetched from the PokéSurvivor repo (cached ~1h).
