Best Type Combos

Game: 4 slots shared by damage moves and buffs (no dedicated buff slot). Only the active slot fires; bonded moves in a slot all tick. Ranker fills the active slot with the best bond. If an ATK buff exists it can sit in the active slot (always on, uses one bond seat) or in another slot (you switch to it — uptime cost). Hover a row for the calculation. Click a move → DPS table.

Off = only buffs in the active slot count. On = buffs in any slot (uptime cost).
